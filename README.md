# Used-Vehicle Price & Transmission Prediction (CSC261 – Project 1)

Machine-learning project for **CSC261 at King Saud University**. It applies two regression techniques to a dataset of 301 used-vehicle listings:

| Part | Question | Model | Headline result (test set) |
|---|---|---|---|
| 1 | What will this vehicle **sell for**? | Linear Regression + K-Fold CV | R² = 0.87, MAE = 1.26 lakh ₹; 5-fold CV RMSE = 1.97 ± 0.28 |
| 2 | Is it **automatic or manual**? | Logistic Regression | Accuracy = 0.90, precision (Automatic) = 1.00, recall (Automatic) = 0.25 |

Prices are in **lakhs of Indian rupees** (1 lakh = ₹100,000).


Run the notebook from the repository root, because it reads `data/car_data.csv` and writes plots to `figures/`. All random seeds are fixed (`random_state = 1`), so the results match the report exactly.

## What the notebook does

**Data cleaning:** removes 2 exact duplicate rows (299 remain) and engineers `Car_Age = 2019 − Year`. It drops `Car_Name` (98 unique values) and `Year`.

**Part 1: Linear Regression (target `Selling_Price`)**
- EDA: summary statistics, price histograms, present-vs-selling scatter, correlation heatmap, prices by category, value retained by age.
- One-hot encoding (`drop_first=True`), 80/20 split (`random_state=1`), standardisation fitted on training data only.
- Coefficients interpreted in lakh ₹. MAE, MSE, RMSE and R² are reported on the train and test sets.
- K-Fold cross-validation with K = 3, 5 and 10 (scaler inside a `Pipeline` to avoid leakage), compared with the single split.

**Part 2: Logistic Regression (target `Is_Automatic`)**
- Stratified 80/20 split and standardised numeric features.
- Coefficients and odds ratios, confusion matrix, accuracy, and precision/recall for the Automatic class.
- Extra checks: stratified 5-fold CV, and `class_weight="balanced"` to show the precision/recall trade-off on imbalanced data (13 % automatic).

## Main findings

- **Price is predictable.** The new (showroom) price, diesel fuel and age are the main drivers; each extra year of age costs about 0.42 lakh. Weak spots: one Land Cruiser far outside the training range, and negative predictions for cheap two-wheelers. A log-price model is the natural next step.
- **Transmission is only partly predictable.** Price is the only strong signal, since expensive vehicles are usually automatic. Mid-priced automatics look identical to manual ones in these features, so recall stays low.
